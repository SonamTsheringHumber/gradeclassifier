## Grade classifier:  

It ask for the user to enter the marks between 0 to 100 and display the grade accordingly

## Setup: 

Python only no external packages required

## How to run this:

python gradeclassifier.py

## Example

Enter your mark: 85 
Output: Your mark is 85.0: Grade A

## Known limitations

This program directly take only one marks and give grade accordingly not average marks of different courses. Also there is no grade level included like A+ or A- etc.
